# TSC specification v3.2.2 (archived)

This is the specification set the shipping OCaml engine (`engine/ocaml/`, binary
`coh`) actually implements. It is **not** part of the normative v4 model in
`spec/`; it is preserved here so a running binary can cite a resolvable
specification rather than a git tag.

See `/STATUS.md` for the relationship between this archive and the v4 specs, and
`docs/design/foundation-contract-reconciliation/DESIGN.md` §10 for the named
exception that permits this archive to live in-tree.
