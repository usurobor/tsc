# TSC — Back to Cohering

This branch is a clean conceptual reset. Its tree imports none of the current
TSC runtime, measurement, or project machinery.

## Original intent

TSC began as an attempt to teach an LLM the operation of **cohering**.

> All is cohering, and cohering is all.

Cohering recursively articulates itself as **coherer** and **cohered**: two
distinct poles of one indivisible process. The triple bar, `≡`, was introduced
to express this without collapsing the poles into identity or splitting them
into independent substances.

The intended use was generative. Given a polarity—mind/body,
observer/observed, limited/unlimited—the model should recover the cohering that
generates both, produce new articulations from it, and return to the original
poles without erasing their difference.

## What went wrong

TSC gradually shifted from teaching this generative operation to specifying and
implementing mechanical measurement. Methodology schemas, property-checker
graphs, runtimes, receipts, and verification became the work itself. The
supporting substrate displaced the phenomenon it was supposed to support.

The result was increasingly elaborate machinery around an increasingly faint
account of cohering.

## What we are doing now

We are returning to the recursive atom: indivisible wholeness articulating
itself as one-as-two.

- `specs/` will contain the smallest precise account of TSC and `≡`.
- `skills/` will contain instructions for applying TSC to real polarities.

The first proof is not a runtime. It is whether an LLM can learn the compact
calculus, recover a non-decorative cohering from an unseen polarity, generate
new consequences, and survive descent back into both poles.

No implementation architecture is presumed until that operation is understood
and demonstrated.
